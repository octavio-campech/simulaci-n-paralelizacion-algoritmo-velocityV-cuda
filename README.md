# Paralelización de Algoritmo Velocity Verlet con CUDA

Este proyecto implementa y optimiza el algoritmo **Velocity Verlet** para simulaciones físicas. El objetivo principal es comparar el rendimiento de una ejecución secuencial (CPU) frente a una paralelizada mediante **CUDA (GPU)** en Google Colab.
